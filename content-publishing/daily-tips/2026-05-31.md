# MySQL indexing strategies

_Generated 2026-05-31_

95% of MySQL performance issues can be resolved with proper indexing strategies, but I still see many production databases suffering from slow queries due to inadequate indexing. When it comes to indexing, I always follow a simple rule - index columns used in WHERE, JOIN, and ORDER BY clauses. For example, if you have a query like this:
```sql
SELECT * FROM customers 
WHERE country='India' AND age>18 
ORDER BY last_name;
```
You should create a composite index on the country, age, and last_name columns. This can significantly speed up your query.
