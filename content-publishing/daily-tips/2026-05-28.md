# Structured logging in Spring Boot

_Generated 2026-05-28_

95% of Spring Boot applications I've seen are still using plain old System.out.println for logging, which is a recipe for disaster in production me. Structured logging is a game-changer, allowing you to log data in a format that's easily parseable by tools like ELK or Splunk. In Spring Boot, you can achieve this using the Logback library and a custom logging configuration. For example, you can create a custom logger like this:
```java
logger.info("User {} logged in with IP {}", username, ipAddress);
```
This will output a log entry with the username and IP address as separate fields, making it easy to analyze and visualize in your logging tool of choice. In scale pe, this can be a huge time-saver when debugging issues. To take it to the next level, you can also use a logging framework like Logstash to parse and transform your log data.
