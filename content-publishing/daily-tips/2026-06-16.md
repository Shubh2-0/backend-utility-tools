# Micrometer + Prometheus integration

_Generated 2026-06-16_

95% of Spring Boot applications I've seen are using Micrometer for metrics, but only a few are actually integrating it with Prometheus - and that's a huge missed opportunity for scale pe. In production me, having a unified view of your application's performance is crucial for identifying bottlenecks and optimizing resources. By integrating Micrometer with Prometheus, you can easily export metrics to Prometheus and visualize them using Grafana. Here's an example of how to do it:
```java
@Bean
public MeterRegistry meterRegistry() {
    SimpleMeterRegistry registry = new SimpleMeterRegistry();
    registry.config().onRefresh(registry);
    return registry;
}

@Bean
public PrometheusConfig prometheusConfig() {
    return new PrometheusConfig();
}

@Bean
public PrometheusMeterRegistry prometheusMeterRegistry(PrometheusConfig config) {
    return PrometheusMeterRegistry.builder(config).build();
}
```
