# Connection pooling with HikariCP

_Generated 2026-06-18_

80% of Java applications still don't use connection pooling effectively, and that's a major performance killer. When working with databases like MySQL, connection pooling is crucial for handling a large number of requests scale pe. That's where HikariCP comes in - a popular, production-ready connection pooling library for Java. I've seen it make a significant difference in production me, especially when dealing with high-traffic microservices.

To get started with HikariCP, you can add the following dependency to your pom.xml:
```java
<dependency>
    <groupId>com.zaxxer</groupId>
    <artifactId>HikariCP</artifactId>
    <version>5.0.1</version>
</dependency>
```
Then, configure your database connection properties:
```java
@Configuration
public class DatabaseConfig {
    @Bean
    public DataSource dataSource() {
        HikariConfig config = new HikariConfig();
        config.setJdbcUrl("jdbc:mysql://localhost:3306/mydb");
        config.setUsername("myuser");
        config.setPassword("mypass");
        return new HikariDataSource(config);
    }
}
```
