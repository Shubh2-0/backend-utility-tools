# Spring Profiles in production

_Generated 2026-06-19_

95% of Spring Boot applications I've seen in production me are not utilizing Spring Profiles to their full potential. As a backend engineer, I've experienced firsthand the benefits of using profiles to manage different environments. By defining separate profiles for dev, staging, and prod, you can easily switch between configurations without modifying code. For example, you can use the `@Profile` annotation to specify different database configurations:
```java
@Configuration
@Profile("prod")
public class ProdDatabaseConfig {
    @Bean
    public DataSource dataSource() {
        return DataSourceBuilder.create()
                .driverClassName("com.mysql.cj.jdbc.Driver")
                .url("jdbc:mysql://prod-db:3306/mydb")
                .username("prod-user")
                .password("prod-password")
                .build();
    }
}
```
