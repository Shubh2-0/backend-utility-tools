# Spring Cache abstraction in production

_Generated 2026-06-17_

95% of Spring Boot applications I've seen in production me use Spring Cache abstraction incorrectly, and it's crazy how much of a performance impact it can have. I've worked with multiple clients who thought they were using caching to improve response times, but in reality, they were just adding unnecessary complexity to their code. 

The problem lies in the fact that most developers don't understand how to properly configure their cache stores. For example, if you're using Redis as your cache store, you need to make sure you're using the correct configuration to avoid cache misses. Here's an example of how to configure Redis as a cache store:
```java
@Bean
public RedisCacheConfiguration cacheConfiguration() {
    return RedisCacheConfiguration.defaultCacheConfig()
            .entryTtl(Duration.ofMinutes(30))
            .disableCachingNullValues();
}
```
